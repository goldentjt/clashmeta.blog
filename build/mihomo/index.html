变更后的复查​

准备工作​

  • 已安装最新稳定版 Mihomo 二进制。

操作步骤​

01
在配置中开启 sniffer 域名嗅探器
配置 TLS/QUIC 嗅探以还原真实的 SNI 目标主机名：
sniffer:
  enable: true
  parse-pure-ip: true
  sniff:
    HTTP:
      ports: [80, 8080-8880]
      override-destination: true
    TLS:
      ports: [443, 8443]
    QUIC:
      ports: [443, 8443]
🔍 核心观察项
当某些应用直接向 IP 发起连接时，嗅探器能通过 TLS 握手 Client Hello 提取出域名，重新送入分流引擎。
02
验证特定新协议支持能力
编写 VLESS + Reality 测试节点并校验语法：
mihomo -t -f ./vless-test.yaml
🔍 核心观察项
确认核心是否原生支持 flow: xtls-rprx-vision 字段。
03
测试多功能规则集合支持
载入基于 geosite 与 rule-providers 的复合规则体系：
mihomo -f ./advanced-rules.yaml
🔍 核心观察项
核查控制台是否成功将大批量规则编译进快速匹配树。

记录本轮输入、预期与实际输出​

  • 实验输入：开启 sniffer 并直接向境外 IP 发起无域名 HTTPS 访问。
  • 预期输出：核心精准还原出原始 SNI 域名，并成功命中分流规则。
  • 回退与恢复方法：将 sniffer 的 enable 改为 false。

常见问题​

支持现代 VLESS、Hysteria2、Tuic 新协议；内置用户态 gVisor TUN 网卡；具备真正的 SNI 协议嗅探与 Fake-IP 缓存持久化。
